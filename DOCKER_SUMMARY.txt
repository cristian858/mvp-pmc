🚀 INICIO RÁPIDO (5 MINUTOS)
═══════════════════════════════════════════════════════════════════════════

1. Copiar .env:
   $ cp .env.docker .env

2. Build (primera vez: 5-10 minutos):
   $ docker-compose build

3. Iniciar:
   $ docker-compose up -d

4. Verificar:
   $ python3 verify_docker.py

5. Acceder:
   ➜ http://localhost:5000/

🛠️ COMANDOS ESENCIALES
═══════════════════════════════════════════════════════════════════════════

Usando helper script (recomendado):
  $ ./docker-helper.sh up          # Iniciar
  $ ./docker-helper.sh logs        # Ver logs
  $ ./docker-helper.sh shell       # Entrar a bash
  $ ./docker-helper.sh down        # Detener
  $ ./docker-helper.sh test        # Verificar

Usando Makefile:
  $ make up                        # Iniciar
  $ make logs                      # Ver logs
  $ make shell                     # Bash
  $ make down                      # Detener
  $ make test                      # Verificar

Usando docker-compose directamente:
  $ docker-compose up -d           # Iniciar
  $ docker-compose logs -f         # Logs
  $ docker-compose exec ... bash   # Bash
  $ docker-compose down            # Detener

💡 TIPS IMPORTANTES
═══════════════════════════════════════════════════════════════════════════

1. Docker es tu mejor amigo:
   - Aísla tu desarrollo del sistema
   - Ambiente reproducible
   - Fácil de compartir

2. Usa el helper script para comenzar:
   - Más intuitivo que docker-compose
   - Colores y mejor output
   - Comandos cortos

3. Lee la documentación según necesites:
   - DOCKER_SETUP.md para empezar
   - DOCKER_GUIDE.md para detalles
   - DOCKER_QUICK_REF.md como referencia

4. Los datos persisten:
   - data/ y instance/ están en tu Mac
   - Puedes detener/iniciar sin perder información
   - Backup: simplemente copia las carpetas

5. El build inicial es lento:
   - Es normal: 5-10 minutos (pre-compilación)
   - Subsecuentes son rápidos: ~30 segundos
   - No hay problema pausar/reanudar


⚠️ TROUBLESHOOTING RÁPIDO
═══════════════════════════════════════════════════════════════════════════

❌ "Port 5000 already in use"
   ➜ FLASK_PORT=8000 en .env

❌ "Cannot connect to Docker daemon"
   ➜ Abrir Docker.app desde Applications

❌ "ModuleNotFoundError"
   ➜ docker-compose build --no-cache

❌ "Contenedor sale inmediatamente"
   ➜ docker-compose logs para ver error

Para más ayuda: DOCKER_GUIDE.md
