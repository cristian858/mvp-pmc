🚨 TROUBLESHOOTING RÁPIDO
═══════════════════════════════════════════════════════════════════════════

"Port 5000 already in use"
  → FLASK_PORT=8000 en .env

"Cannot connect to Docker daemon"
  → Abrir Docker.app desde Applications

"Build fails"
  → docker-compose build --no-cache

"Module not found"
  → Reconstruir: docker-compose build --no-cache

"BD corrupta"
  → rm instance/safesign.db + reiniciar

"Volúmenes no persisten"
  → Crear directorios: mkdir -p data/uploads data/capturas data/signatures instance

Para más ayuda: DOCKER_GUIDE.md (sección Troubleshooting)
